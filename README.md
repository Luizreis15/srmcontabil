# SMR Assessoria Contábil

Site institucional da SMR Assessoria Contábil — inteligência fiscal para empresas do ABC.

## Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Desenvolvimento local

Requisito: Node.js e npm.

```sh
npm i
npm run dev
```

O servidor sobe em [http://localhost:8080](http://localhost:8080).

### Scripts

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run preview` | Preview do build |
| `npm run lint` | ESLint |
| `npm test` | Testes (Vitest) |

## Rotas

- `/` — Landing page (site principal)
- `/links` — Hub de links
